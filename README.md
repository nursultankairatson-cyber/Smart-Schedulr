Smart-Schedulr — Умное расписание пар и экзаменов

Веб-приложение для управления учебным расписанием и экзаменами в рамках проекта по курсу INF 106 — Introduction to ICT and Computer Systems.

Live Demo
https://nursultankairatson-cyber.github.io/Smart-Schedulr/

Основные функции
Поиск по предмету, преподавателю, аудитории или дню недели.
Быстрые фильтры по дням (`Все дни`, `Сегодня`, `Пн–Пт`).
Определение и подсветка текущей и следующей пары по времени и дню недели.
Проверка конфликтов при добавлении пары (пересечение по времени и занятость кабинета).
Учёт экзаменов с отсчётом дней до даты.
Сохранение данных в `localStorage`.
